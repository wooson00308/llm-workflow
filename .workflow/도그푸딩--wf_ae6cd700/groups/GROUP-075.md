# 품질 확인 카드에 기능 소개의 첫 문장만 보여주기

## 기능 설명

품질 확인 목록의 기능 카드에는 기능 소개의 첫 문장 하나만 실린다. 소개가 몇 문단이든 카드에
보이는 글은 문장 하나이고, 그 문장은 마침표까지 온전히 보인다. 카드마다 제목 한 줄과 문장
하나라는 같은 모양이 되므로 확인 대기 목록을 위에서 아래로 훑는 것만으로 어떤 기능이 확인을
기다리는지 알 수 있다.

첫 문장 뒤의 설명은 카드에서 사라지지만 없어지지는 않는다. 시작을 눌러 들어간 확인 화면의
머리말과 완료 기록 화면의 기능 상세는 지금과 똑같이 소개 전체를 문단 구분까지 살려서
보여준다. 배경 설명이 필요한 사용자는 그 두 자리에서 읽는다.

카드에 소개를 펼치는 조작은 두지 않는다. 카드는 통째로 눌러 확인을 시작하는 입구이고, 그
동선은 이번 변경으로 달라지지 않는다.

## 품질 확인 방식

사용자 확인으로 둔다. 이 그룹이 바꾸는 것은 카드에 무엇이 실리고 카드가 어떤 높이로 서는지이며,
둘 다 저장소를 열지 않고 앱 화면만으로 판단할 수 있다.

확인에 필요한 자료도 이미 저장소에 있다. 2026-08-19 기준 기능 문서 70건 가운데 15건의 소개가
4문장 이상이고 가장 긴 것은 5개 문단 17문장이며, 나머지 55건은 1문장에서 2문장이다. 사용자가
따로 상태를 만들지 않아도 확인 대기 목록에서 두 형태를 함께 만난다.

기획서의 완료 판정 기준 일곱 항목 중 다섯이 화면에서 눈으로 확인된다. 남은 둘은 자동 검증이
맡는다. 소개가 없는 기능의 카드가 제목만 보여주는지는 지금 저장소에 소개가 빈 기능 문서가 없어
화면에서 만들 수 없으므로 단위 시험으로 확인하고, 기존 기능 문서 70건이 변경 전후로 같은지는
이 그룹의 작업이 문서 파일을 고치지 않는다는 완료 조건으로 확인한다.

## 작업 구성

작업 하나로 둔다. 나누지 않은 이유는 이 변경이 저장소에서 한 화면의 한 자리에 모여 있기
때문이다.

바꿀 것은 세 가지다. 소개에서 첫 문장을 잘라 내는 규칙 하나를 새로 만들고, 품질 확인 대기열
카드가 소개 전체 대신 그 값을 쓰게 하고, 카드의 줄 수 상한을 세 줄에서 두 줄로 내린다. 셋은
같은 화면 폴더 안에 있고, 셋이 모두 반영되어야 기획서가 요구하는 결과가 나온다.

특히 줄 수 상한만 먼저 반영되면 카드가 지금 값 그대로 두 줄에서 끊겨, 지금보다 짧게 잘린
문장을 보여주는 상태가 된다. 이 상태를 만들지 않으려면 첫 문장 규칙과 줄 수 상한이 함께
반영되어야 하고, 그래서 둘을 한 작업으로 묶었다.

기획서의 R4와 R6은 이 작업이 새로 만들지 않는다. 카드에 펼치기 조작이 없고 카드를 누르면
확인이 시작되는 동선은 지금 코드가 이미 그렇고, 소개가 비었을 때 카드가 제목만 보여주는 것도
지금 코드가 이미 그렇다. 두 가지는 이 작업의 완료 조건에서 그대로 유지되는지만 확인한다.

지금 이 저장소에 진행 중인 다른 작업이 없고, 이 작업이 선언한 파일을 앞선 그룹의 남은 작업이
잡고 있지도 않다. 그래서 이 그룹 안팎 어디에도 순서를 두지 않았다.

## 이번 그룹이 다루지 않는 것

확인 화면의 머리말과 완료 기록 화면의 기능 상세가 소개를 보여주는 기준은 바꾸지 않는다.
SPEC-066이 정한 대로 줄 수 제한 없이 문단 구분을 살려 보여준다.

기능 문서에서 소개 문단을 뽑는 규칙 자체도 바꾸지 않는다. 앱이 읽어 오는 소개 값은 지금과
같고, 이 그룹은 그 값에서 카드에 무엇을 실을지만 정한다. 기존 기능 문서도 한 건도 고치지
않는다.

아키텍트가 기능 문서의 소개 첫 문장에 무엇을 쓸지 정하는 작성 지침도 다루지 않는다. 첫 문장이
기능의 변화가 아니라 상황 설명으로 시작하는 문서가 실측 70건 중 1건 있었고, 그 기능의 카드는
지금보다 정보가 줄어든다. 기획서가 이를 별도 아이디어로 넘겼다.

### QA-01 · 확인 대기 목록에서 기능 소개 읽고 확인 화면으로 들어가기

1. 앱에서 품질 확인 화면을 연다.
   > 지금 확인할 기능 목록에 기능 카드가 세로로 늘어서고, 카드마다 기능 이름 아래에 문장
   > 하나가 보인다.
2. 카드 하나를 골라 그 문장을 처음부터 끝까지 읽는다.
   > 문장이 마침표까지 온전히 보이고, 그 마침표 뒤로는 아무 글자도 이어지지 않는다. 다음
   > 문장의 첫 낱말이 시작되다 말고 끊긴 자리가 없다.
3. 목록을 위에서 아래로 훑으면서 카드 높이를 비교한다.
   > 소개가 긴 기능이든 짧은 기능이든 카드 높이가 서로 같다.
4. 카드 안에 소개를 펼치는 버튼이나 더 보기 표시가 있는지 살펴본다.
   > 카드에는 기능 이름과 문장 하나와 시작 표시만 있고, 소개를 펼치는 조작은 어디에도 없다.
5. 소개가 길어 보이는 기능의 카드를 눌러 확인을 시작한다.
   > 카드를 누른 것만으로 확인 화면이 열리고, 머리말에 그 기능의 소개가 잘리지 않고 전부
   > 보인다. 소개가 여러 문단인 기능이면 문단 사이가 벌어져 구분되어 보인다.
6. 목록으로 돌아가 방금 연 기능의 카드를 다시 본다.
   > 카드에는 머리말에서 읽은 소개의 첫 문장만 실려 있고, 둘째 문장부터는 보이지 않는다.
7. 완료 기록 화면을 열고 기록된 기능 하나를 펼친다.
   > 기능 상세에 소개가 확인 화면 머리말과 같은 기준으로 보인다. 줄 수 제한 없이 전부 보이고
   > 문단 구분이 살아 있다.
