# 새 기기 준비 단계를 하나의 안내로 잇고 실행 권한 동의를 상시 열기

## 기능 설명

에이전트 화면 위쪽에 남은 준비 단계만 담은 안내가 하나 선다. 관리형 서비스 연결, 실행 권한 동의,
자동 배정 켜기가 이 순서로 서 있고, 각 단계를 그 자리에서 실행한다. 이미 마친 단계는 완료로
표시되고 버튼을 제공하지 않으며, 세 단계가 모두 끝나면 안내는 통째로 사라진다.

실행 권한 동의는 자동 배정이 꺼져 있어도 이 안내에서 열 수 있다. 고급 설정의 동의 자리에서도
고지를 읽고 동의를 기록할 수 있다. 동의만 기록하는 경로는 자동 배정 설정을 저장하지 않으므로,
동의한 뒤에도 자동 배정은 꺼진 채로 남는다. 새 기기 사용자는 동의하려고 일감을 먼저 만드는 역순
없이 화면이 세워 준 순서대로 준비를 끝낸다.

동의 관문 자체는 지금 그대로다. 고지 문구와 버전 판정, 동의 없이는 세션을 시작하지 않는 실행
조건, 직접 배정 흐름 안의 동의, 동의 철회 절차, 자동 배정 토글의 상시 자리는 달라지지 않는다.
동의를 물어볼 수 없는 실행 환경에서는 동의 단계가 사유만 보여주고 완료로 표시하지 않는다.

### QA-01 · 준비 안내로 동의부터 자동 배정까지 한 번에 밟기

1. 앱에서 에이전트 화면을 연다.
   > 화면 제목 아래에 자동 배정 토글과 실행 목록이 보인다.
2. 자동 배정이 켜져 있으면 토글을 눌러 끈다. 이미 꺼져 있으면 그대로 둔다.
   > 자동 배정이 꺼진 상태로 표시된다.
3. 고급 설정을 열고 실행 권한 동의 자리를 펼친다.
   > 동의 여부가 동의함으로 보이고 동의 철회 버튼이 있다.
4. 동의 철회를 누르고 확인 창에서 동의 철회를 한 번 더 누른다.
   > 동의 여부가 동의 필요로 바뀌고, 같은 자리에 고지를 읽고 동의를 기록하는 버튼이 함께 보인다.
5. 고급 설정을 닫고 에이전트 화면 위쪽을 본다.
   > 화면 제목 아래, 자동 배정 토글 위에 준비 안내가 하나 나타난다. 관리형 서비스 연결, 실행 권한 동의, 자동 배정 켜기가 이 순서로 서 있고, 이미 마친 관리형 서비스 연결은 완료로 표시되어 버튼이 없다.
6. 안내의 실행 권한 동의 단계에서 버튼을 눌러 고지를 읽고 동의한다.
   > 동의 화면이 열려 고지 전문과 동의 확인란이 보이고, 동의를 기록하면 안내의 동의 단계가 완료로 바뀐다. 직접 배정을 하나도 만들지 않고 동의에 닿았다.
7. 동의를 기록한 직후 자동 배정 토글을 본다.
   > 자동 배정은 꺼진 채로 남아 있고, 안내에는 자동 배정 켜기만 남은 단계로 보인다.
8. 안내의 자동 배정 켜기 단계에서 버튼을 눌러 확인 창을 열고 자동 배정을 켠다.
   > 자동 배정 토글을 직접 눌렀을 때와 같은 확인 창이 열리고, 켜기를 마치면 자동 배정이 켜진 상태로 바뀐다.
9. 자동 배정을 켠 뒤 화면 위쪽을 다시 본다.
   > 준비 안내가 통째로 사라지고, 화면에는 자동 배정 토글과 실행 목록이 안내가 나타나기 전과 같은 구성으로 남는다.
