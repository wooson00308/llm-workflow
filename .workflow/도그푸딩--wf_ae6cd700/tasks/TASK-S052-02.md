# 구조화된 요약을 추측 없이 판정하고 값으로 분리한다

## 결정권자 요약

정확한 요약 형식을 갖춘 문서만 결정 보드가 읽을 값으로 분리한다.
항목이 비거나 빠지고, 순서나 제목이 달라진 문서는 값을 추측하지 않고 기존 평문 표시로 돌아간다.
원문은 바꾸지 않았고 네트워크와 저장소를 쓰지 않는 순수한 판정만 추가했다.
자동 검사와 타입 검사가 모두 통과했으며, 사용자는 아래 동선으로 QA를 확인할 수 있다.

## 확인 동선

이 작업은 화면 대신 자동 검사로 확인한다.
프로젝트 루트에서 `npx vitest run src/features/projects/domain/documentSections.test.ts`를 실행해
45개 검사가 모두 통과하는지 확인한다.
이어서 `npm run typecheck`을 실행해 TypeScript 검사도 성공하는지 확인한다.
두 결과가 같으면 사용자 QA 확인은 자동 검사 결과를 신뢰하는 것으로 완료한다.

## 목적

기존 절 분리 모듈에 구조화된 결정권자 요약을 판정하는 순수 함수를 추가한다. 함수는
`splitSection`이 잘라 낸 `## 결정권자 요약` 원문 조각을 받아 화면이 사용할 명시적 값 모델이나
`null`을 돌려준다. Markdown을 저장용 HTML로 바꾸거나 문장 의미를 분석하지 않는다.

## 입력 문법과 반환 값

필수 하위 제목은 `제안`, `현재`, `변경 후`, `사용자 결과`, `영향 범위`, `결정 요청`이며 정확한
`###` 깊이와 이 순서를 사용한다. `비용과 위험`만 `영향 범위`와 `결정 요청` 사이에 선택적으로 올 수
있다. 각 제목은 한 번만 쓴다. 보이지 않는 줄 끝 공백은 기존 절 판정과 같이 무시할 수 있지만 제목의
철자, 내부 공백과 깊이는 정규화하지 않는다.

일반 항목은 다음 하위 제목 전까지의 Markdown 원문을 가장자리 공백만 걷어 반환하며 값이 비어 있으면
전체 구조를 거절한다. 제목과 값 사이의 빈 줄, 값 안의 일반 줄바꿈은 허용한다. 알 수 없는 Markdown
제목이나 다른 깊이의 제목이 요약 절 안에 있으면 구조를 거절한다.

`영향 범위`는 아래 두 목록 항목만 이 순서로 허용한다.

```markdown
- 변경: 비어 있지 않은 값
- 유지: 비어 있지 않은 값
```

별표 목록, 표식 철자 변형, 순서 변경, 중복, 한쪽 누락, 빈 값, 그 밖의 목록이나 평문이 있으면 전체
구조를 거절한다. 반환 모델은 `proposal`, `current`, `after`, `userResult`, `changed`, `unchanged`,
선택적 `risk`, `decisionRequest`처럼 화면이 항목을 추측하지 않고 읽을 수 있는 명시적 필드를 가진다.

## 폴백 경계

다음 입력은 예외를 던지거나 일부 값을 반환하지 않고 `null`을 돌려준다.

- 평문 결정권자 요약과 요약 절이 없는 본문.
- 필수 제목이나 영향 표식이 하나라도 없거나 값이 빈 문서.
- 제목·표식이 반복되거나 순서·깊이·철자가 다른 문서.
- 선택 항목이 정해진 위치가 아닌 곳에 있거나 값이 빈 문서.
- 구조 안에 알 수 없는 제목이나 영향 범위의 추가 내용이 있는 문서.

기존 `splitSection`의 절 경계, 코드 펜스 처리, 첫 번째 요약 절 선택과 원문 보존 동작은 달라지지
않는다. 불완전한 구조의 원문은 후속 화면이 기존 `MarkdownBody`에 그대로 넘길 수 있어야 한다.

## 완료 조건

1. 구조를 모두 갖춘 요약이 여덟 값과 선택적 위험 값을 정확히 반환한다. 위험이 없을 때는 빈 문자열이
   아니라 필드 부재로 표현된다. (R1·R5)
2. 필수 제목과 선택 제목의 정확한 깊이·철자·순서·단일성만 인정하고 비슷한 표현을 추측하지 않는다.
   (R1·R3)
3. 영향 범위가 `변경`과 `유지` 두 값을 정한 순서로 한 번씩 가질 때만 인정된다. (R1·R2)
4. 빈 값, 누락, 반복, 순서 변경, 다른 깊이, 알 수 없는 제목, 잘못된 영향 표식의 표형 테스트가 모두
   `null` 폴백을 확인한다. 일부 값으로 보드를 만들지 않는다. (R3)
5. 반환한 각 값은 문서의 Markdown 조각을 의미 변환하거나 HTML로 만들지 않은 값이다. 원문 본문과
   `splitSection` 반환값은 수정되지 않는다. (R3·R5)
6. 기존 평문·무요약·코드 펜스·중복 요약 절 검사가 수정 없이 통과한다.
7. 구현은 브라우저 API, 파일 저장, 네트워크와 LLM 의존성이 없는 순수 TypeScript다. 새 패키지를
   추가하지 않는다. (R5)
8. `npx vitest run src/features/projects/domain/documentSections.test.ts`와 `npm run typecheck`이
   통과한다.

## 검증 절차

1. 완전한 구조 두 벌로 위험 항목의 있음·없음과 모든 반환 값을 확인한다.
2. 필수 제목·값·영향 표식마다 한 가지씩 결함을 만든 표형 픽스처로 폴백을 확인한다.
3. 평문 요약과 불완전 구조를 `splitSection`으로 자른 뒤 반환된 원문이 입력과 같은지 확인한다.
4. `npx vitest run src/features/projects/domain/documentSections.test.ts`와 `npm run typecheck`을 실행한다.
