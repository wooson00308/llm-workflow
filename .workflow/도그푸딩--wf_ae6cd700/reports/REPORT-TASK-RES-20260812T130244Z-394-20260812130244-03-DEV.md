## 결정권자 요약

실행 상세를 이벤트 나열에서 요약 카드 하나로 바꿨다. 대상 문서와 역할, 시작과 경과, 상태와 사유,
도구 사용 총 횟수와 유형별 집계, 마지막 활동 시각이 한 카드에 모인다. 진행 이벤트와 도구 이벤트는
집계에만 반영하고 개별 줄로 남기지 않으며, 줄로 남는 것은 시작과 종료, 실패 상세, 활동 없음 신호뿐이다.
도구는 파일 읽기, 파일 편집, 명령 실행, 검색으로 묶고 알지 못하는 이름은 기타로, 이름이 없는 옛 기록은
이름 없음으로 센다. 도구 이름 원문은 화면 어디에도 나가지 않는다.
활동이 5분 이상 없으면 신호가 나타나고 새 이벤트가 오면 사라지며, 이 신호는 실행 상태를 바꾸지 않는다.
상세가 열려 있는 동안만 이벤트를 이어 읽고 닫으면 멈춘다. 기록을 읽지 못한 항목은 모름으로 남기고
직전 실행의 값을 현재 사실로 보여 주지 않는다.
검사 469개가 통과했고 형식 검사와 빌드도 통과했다. 사용자는 작업 문서의 확인 동선 여섯 가지를 화면에서
확인하면 된다.

## 남은 위험

- 도구 이름을 유형으로 묶는 표는 Claude가 쓰는 이름과 Codex가 항목 유형으로 싣는 이름을 담았다. provider가
  새 이름을 쓰기 시작하면 그 도구는 기타로 세어지고 총 횟수에는 그대로 들어간다. 숫자가 틀리지는 않지만
  유형 구분이 거칠어지므로, 기타가 눈에 띄게 늘면 표를 다시 봐야 한다.
- 활동 없음 판정은 화면이 다시 그려질 때 계산한다. 상세가 열려 있으면 2.5초 주기가 다시 그리므로 문제가
  없지만, 이어 읽기가 실패해 응답이 오지 않는 동안에는 신호가 나타나는 시점이 그만큼 늦어질 수 있다.
- 이벤트 시각은 저장된 실행 시작 시각과 경과 초로 계산한다. 런타임이 두 값 중 하나를 싣지 않은 이벤트에서는
  마지막 활동 시각이 그 이벤트를 반영하지 않고 직전 값에 머문다. 지어내지 않는 쪽을 골랐다.
- 화면을 실제로 띄워 눈으로 본 확인은 하지 않았다. 표시 규칙은 자동 검사가 요소의 구조와 문구까지 확인하지만
  간격과 색은 확인 동선에서 사용자가 본다.
