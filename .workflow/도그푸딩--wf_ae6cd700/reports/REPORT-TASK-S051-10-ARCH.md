# TASK-S051-10 아키텍트 수리 보고서

## 결정권자 요약

에이전트 실행 대시보드를 실제 앱 메뉴에서 여는 데 필요한 최상위 연결 파일을 작업 범위에 추가했다.
선행 작업이 화면과 메뉴 통로를 이미 만들었으므로 새 기능이나 새 결정을 더하지 않았다.
개발자는 작업 공간이 준비한 상태와 조작을 화면 껍데기에 넘기는 두 줄을 대시보드 구현과 함께 완성한다.
막힘 근거와 이력은 보존했고 작업은 다시 개발 가능한 상태로 돌려놓았다.

## 잘못된 정의

TASK-S051-09가 `WorkspaceShell`에 에이전트 메뉴와 화면을 만들었지만, 실제 앱의 최상위 조립부는
`useProjectWorkspace`가 반환하는 에이전트 상태와 조작을 `WorkspaceShell`에 넘기지 않는다.
TASK-S051-10의 완료 조건은 실제 화면 진입을 요구하면서도 그 연결을 고칠 `src/App.tsx`를
`scope_files`에 선언하지 않았다. 개발자가 기존 범위를 지키면 완료 조건 1과 실제 앱 확인 동선을
충족할 수 없는 정의 오류였다.

반면 `src/features/projects/components/WorkspaceShell.tsx`는 TASK-S051-09가 두 선택 속성, 메뉴 노출,
화면 렌더 조건을 이미 구현했다. 이 파일을 바꾸지 않고 최상위 호출에 두 전달값만 더하면 실제 앱 진입이
성립한다. 승인된 SPEC-051의 에이전트 화면 요구를 완성하는 연결이므로 기획 범위를 넓히지 않는다.
