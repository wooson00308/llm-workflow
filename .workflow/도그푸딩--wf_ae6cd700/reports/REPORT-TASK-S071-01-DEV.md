# TASK-S071-01 개발 보고서

## 결정권자 요약

실행 도구의 사용 한도에 걸려 끝난 실행이 실행 기록에 실려 오면, 앱이 그것을 일반 실패와 구분해 받아
어느 실행 도구를 언제 다시 쓸 수 있는지를 사용자 홈 아래 기기 단위 기록으로 남긴다. 해제 예정 시각이
함께 오면 그 시각을 쓰고, 오지 않으면 종료 시각의 한 시간 뒤를 쓰되 두 경우를 기록에서 구별한다.
한도 판정의 근거는 실행 환경이 실은 종료 사유 값 하나이며 실패 메시지 원문을 훑지 않는다. 지금 보류
중인 실행 도구 목록이 실행 목록 응답에 함께 실려, 뒤이을 배정 보류와 화면 표시가 같은 기록 위에서
이루어진다. 이 세션은 앞 세션이 선점 만료로 멈춘 자리를 이어받아, 이미 통합된 제품 코드를 공유
기준에서 다시 검사했다. 백엔드 884건과 통합 시험 28건, 화면 시험 505건이 통과했고 형식 검사와 정적
분석, 생산 빌드도 통과했다. 이 결과는 GROUP-071의 자동 검증 가운데 기록을 만드는 부분을 뒷받침한다.

## 변경한 파일과 모듈

선언한 다섯 파일만 바뀌었고 `.workflow` 아래 문서는 제품 코드 커밋에 섞이지 않았다(C16, C19).

- `src-tauri/src/domain/agent_runtime.rs`: `RunSummary`에 선택 항목 `usage_limit_resets_at`을 더했다
  (JSON 이름 `usageLimitResetsAt`, `#[serde(default)]`). 한도 구분값 `USAGE_LIMIT_REACHED`, 판정
  `reached_usage_limit`, 끝난 상태를 모은 `RunState::is_finished`, 응답이 실을 `ProviderHold`를 같은
  모듈에 두었다(C1, C2, C13).
- `src-tauri/src/infrastructure/provider_hold.rs`(새 파일)와 `src-tauri/src/infrastructure/mod.rs`:
  기록 자리는 인자로 받은 루트 아래 `provider-holds/<실행 도구 이름>.yml` 하나다(C3). 여섯 줄을 정해진
  순서로 직접 조립해 쓰고(C4), 재개 시각은 해제 예정 시각이 있으면 그 시각, 없으면 종료 시각의 한
  시간 뒤다(C5). 이름이 정해진 문자 밖이면 경로를 만들지 않고(C6), 같은 실행으로는 다시 쓰지 않으며
  (C8), 이미 지난 재개 시각은 기록하지 않는다(C9). 조회는 파일 이름에서 읽은 실행 도구 이름을 쓰고
  (C10), 만료된 기록은 보류로 답하지 않으면서 파일을 그대로 두며(C11), 없거나 깨진 기록은 보류 없음
  으로 답한다(C12).
- `src-tauri/src/application/agent_runtime_status_service.rs`: `inspect`가 보류 기록 루트를 선택
  인자로 받는다. `usage_limit_ends`가 종료 사유와 끝난 상태와 종료 시각을 모두 만족하는 행만 고르고,
  실행 도구마다 종료 시각이 가장 늦은 행 하나만 근거로 삼는다(C7). `QueueSnapshot`의 `provider_holds`
  를 채우며, 기록을 쓰거나 읽지 못해도 조회는 성공한다(C13, C14).
- `src-tauri/src/commands/agent_runtime.rs`: `provider_hold_root`가 홈에 `.workflow-labs`를 붙여
  서비스에 넘긴다. 홈을 얻지 못하면 보류 기록 없이 지금과 같이 조회한다(C15).

## 남은 위험

- 실행 환경이 아직 구분값과 해제 예정 시각을 싣지 않는다. 실제 한도 상황에서 기록이 생기는 장면을
  사람이 확인한 적은 없고, 검사에서 만든 실행 행으로만 확인했다.
- 기록은 직접 조립한 여섯 줄이고 읽기는 YAML 해석기가 한다. 두 자리가 갈라지지 않도록 본문 전체를
  글자 그대로 대조하는 검사를 두었다. 뒤이을 조건 검사가 이 형식을 읽으므로, 형식을 바꾸면 그 검사가
  먼저 깨진다.
- 실행 식별자에 줄바꿈이나 콜론이 들어오면 기록이 깨질 수 있다. 그 경우 조회가 보류 없음으로 답하므로
  배정이 멈추는 쪽으로 틀어지지는 않는다.
