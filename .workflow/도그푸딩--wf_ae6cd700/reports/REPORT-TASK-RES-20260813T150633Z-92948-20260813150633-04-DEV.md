## 결정권자 요약

품질 확인 화면에서 기능을 연 뒤 항목을 하나씩 확인하는 본문을 만들었다. 왼쪽에 확인 항목 목록을,
오른쪽에 지금 볼 항목 하나를 놓고, 위쪽 고정 줄이 기능 이름과 진행률을 늘 보여 준다. 현재 항목에는
개발자가 작업 문서에 쓴 확인 동선 절이 발췌가 아니라 통째로 실린다. 항목마다 확인함 또는 문제 있음을
고르고 메모를 남길 수 있으며, 문제 있음은 사유를 적어야 결과로 확정된다. 남긴 내용은 이 기기에만
저장되어 다른 화면에 갔다 와도 이어지고, 작업 문서와 결정 기록에는 아무것도 쓰지 않는다. 새 화면 검사
10건, 대기열 화면 검사 11건, 저장소 전체 검사 550건과 타입 검사가 통과했다. 사용자는 항목이 하나도
빠지지 않는지, 확인 동선이 전체로 보이는지, 문제 있음이 사유를 요구하는지, 화면을 떠났다 와도 남긴
내용이 그대로인지를 확인하면 된다. 제출 조작은 아직 없고 결정을 남기는 길은 개발 화면 하나뿐이다.
