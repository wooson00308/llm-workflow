## 결정권자 요약

실행 하나의 진단 자료를 파일로 저장하거나 클립보드로 복사하는 길을 실행 상세에 더했다.
저장과 복사는 같은 조립을 한 번만 지나므로 두 결과의 규격 버전과 실행 내용이 같고 생성 시각만 다르다.
이벤트는 저장 계층의 한 번 조회 한도에서 끊지 않고 더 읽을 것이 없을 때까지 이어 읽어 전체를 담는다.
진단이나 오류를 읽지 못해도 조립을 멈추지 않고, 읽은 부분을 담은 뒤 빠진 항목의 이름과 사유를 함께 적는다.
자료에 실리는 값은 계약이 정한 항목으로 한정했다. 작업 지시와 프롬프트와 인증 값과 환경 변수와 도구 인자와
도구 결과 본문은 자리 자체가 없으므로 런타임이 그런 값을 더 실어 보내도 옮겨지지 않는다.
내보내기는 사용자가 저장이나 복사를 고른 때만 실행되고, 외부로 보내는 경로는 더하지 않았다.
저장 대화상자에 필요한 권한은 이미 열려 있어 권한 파일은 손대지 않았다.
백엔드 검사 738개와 화면 검사 487개가 통과했다. 사용자는 이 작업의 확인 동선대로 저장과 복사를 한 번씩
해 보고, 결과 파일에 금지된 값이 없는지 확인하면 된다.
