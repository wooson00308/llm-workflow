# TASK-137 개발 보고서

## 결정권자 요약

설정 화면에 프로젝트별 `사용자 정의 규칙` 편집 카드를 추가했다.
사용 여부와 세 역할, Markdown 본문을 한 초안으로 편집하고 저장하지 않은 변경을 구분한다.
백엔드가 만든 저장 파일 원문과 역할별 세 규칙 출처를 저장 전에 그대로 확인해야 저장할 수 있다.
편집 중 외부 변경이나 저장 충돌이 생기면 입력을 유지하고 다시 불러오기 전까지 저장을 막는다.
형식 오류와 미래 스키마는 원문을 먼저 보여주며, 심볼릭 링크 같은 안전하지 않은 파일은 덮어쓰지 않는다.
Markdown 미리보기는 원시 HTML, 링크와 외부 이미지를 실행 가능한 DOM으로 만들지 않는다.
비밀 값 금지, 앱 규칙 우선, 다음 세션 적용과 활성 lease 안내를 카드에 항상 표시한다.
프런트엔드 전체 검사 760개와 타입 검사, 배포 빌드, 변경 공백 검사가 통과했다.
사용자는 TASK-137 확인 동선으로 실제 파일 저장과 외부 변경 처리를 확인하면 된다.

## 구현 내용

### 편집과 확인 절차

- 파일 없음은 꺼진 빈 초안으로, 정상 파일은 저장된 사용 여부·역할·본문·수정 시각으로 시작한다.
- 규칙을 꺼도 역할과 본문을 보존하고, 켠 상태에서는 역할 하나 이상을 요구한다.
- 초안 변경은 기존 미리보기와 저장 알림을 즉시 무효화한다. 마지막으로 불러온 값과 같은 미리보기가
  있을 때만 저장 버튼을 활성화한다.
- 본문 전체 삭제는 별도 확인을 거치며, 변경 취소는 디스크를 읽지 않고 마지막 기준 값으로 돌아간다.
- 형식 오류와 미래 스키마는 오류와 원문을 먼저 보여준 뒤 명시적인 덮어쓰기 확인으로만 빈 안전 초안을
  연다. 안전하지 않은 파일에는 덮어쓰기 동작을 제공하지 않는다.

### 미리보기와 외부 변경

- 백엔드가 반환한 직렬화 원문은 줄바꿈을 유지한 읽기 전용 원문으로 표시한다.
- 기획자·아키텍트·개발자 탭에서 세 출처의 순서, 적용 여부, 제외 사유와 내용을 가공하지 않고 표시한다.
- 사용자 본문 Markdown은 HTML을 건너뛰고 링크와 이미지를 비대화 요소로 바꿔 탐색과 외부 요청을 막는다.
- 불러온 파일 식별값이 바뀌거나 저장 충돌이 반환되면 초안을 유지하고 저장을 막는다. 사용자가 다시
  불러오기를 선택할 때만 최신 디스크 상태를 초안 기준으로 삼는다.
- 다시 불러오기 실패 시에도 저장하지 않은 초안을 버리지 않는다. 잠금 재시도는 자동 재시도하지 않는다.

### 화면 연결

- `App`에서 작업 공간의 사용자 규칙 상태와 동작을 `WorkspaceShell`, `SettingsView`,
  `CustomRulesCard`까지 필수 속성으로 전달한다.
- 사용자 규칙 오류는 관리 규칙 오류와 별도 카드에 남고, 사이드바 이동과 프로젝트 전환은 계속 동작한다.
- 기존 관리 규칙 카드와 알림은 변경 없이 같은 설정 화면에 유지한다.

## 검증 결과

- `npm test -- src/features/projects/components/CustomRulesCard.test.tsx --maxWorkers=1`: 17개 통과.
- 설정 화면과 작업 공간 배선 집중 검사: 3개 파일 57개 통과.
- `npm run check`: 타입 검사 통과, 24개 파일의 프런트엔드 검사 760개 통과, 배포 빌드 성공.
- `git diff --check`: 통과.
- 원시 HTML, 일반·위험 URL 링크와 외부 이미지를 넣어 `script`, `a`, `img` 요소가 생기지 않음을
  확인했다.
- 파일 없음, 정상, 형식 오류, 미래 스키마, 안전하지 않은 파일, 외부 변경, 충돌, 잠금 재시도와 읽기·
  미리보기·저장 오류 경로를 확인했다.
- 이번 작업은 Rust 파일을 바꾸지 않아 Rust 검사는 다시 실행하지 않았다. TASK-135의 전체 Rust 검사
  574개와 정적 검사 결과를 사용한다.

## 남은 위험과 후속

- 실제 운영체제 파일 교체와 에이전트의 다음 세션 적용은 Tauri 개발 앱에서 사용자가 확인해야 한다.
- 빌드의 500 KiB 청크 경고는 기존 경고이며 이번 작업의 실패 조건은 아니다.
- 여러 규칙 문서, 전역 규칙, 조건부 적용, 템플릿과 의미 기반 충돌 검사는 추가하지 않았다.
