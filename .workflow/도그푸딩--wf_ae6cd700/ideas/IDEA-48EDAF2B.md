하트비트 설치 안내를 단계별 마법사로 강화한다. 대행 설치는 하지 않는다.

- 배경: 미설치 상태의 안내가 명령 두 줄이라, 처음 설치하는 사용자는 어디까지 됐는지 앱에서 알 수 없다.
- 원칙 합의: 앱이 pip 등 외부 명령을 대행 실행하는 원버튼 설치는 하지 않는다. 앱의 "외부 명령 비실행" 성질은 계약급 원칙이고, GUI 앱의 PATH 불확실성과 반쯤 설치된 상태의 오탐 위험이 크다. 실행은 사용자의 터미널에서, 앱은 안내와 감지를 맡는다.
- 방향: 설치 마법사 — 단계별 체크리스트(패키지 설치 → init → 서비스 등록 → (선택) dream 스킬), 각 단계의 명령 복사 버튼, 그리고 "다시 확인" 버튼으로 앱이 단계별 완료를 재감지해 체크가 실시간으로 채워지게 한다.
- 감지는 전부 기존 방식(파일 존재·상태 파일)의 읽기 전용이다. 단계별 감지 기준을 정의하는 것이 기획의 핵심이다.
