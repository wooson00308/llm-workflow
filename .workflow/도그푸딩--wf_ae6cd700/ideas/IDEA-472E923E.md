LLM Workflow에 선택적 연동(플러그인) 개념을 도입하고 첫 연동으로 claude-heartbeat를 제공한다.

- 설정 화면에 연동 섹션을 만든다. 하트비트 설치를 감지해 미설치면 설치 안내를, 설치돼 있으면 "이 프로젝트에 역할 잡 설치" 버튼을 제공한다.
- 기본 세팅 제공: 기획자·아키텍트·개발자 잡 3종(model, interval, max_per, 조건 포함)을 ~/.claude/HEARTBEAT.md의 앱 관리 마커 블록에 기록한다. AGENTS.md 관리 블록과 같은 패턴으로 사용자 수동 잡과 공존한다.
- 조건 스크립트(wf-eligible)는 역할 계약처럼 앱 관리 자산으로 .workflow/rules/에 설치하고 버전 관리한다.
- 관리 UI: 역할별 활성 토글, 주기·쿼터·모델 편집, 데몬 상태와 마지막 실행 결과 표시(하트비트 상태 파일 읽기 전용).
- 원칙: 앱은 LLM도 하트비트도 실행하지 않는다. 파일 계약 관리와 상태 표시만 한다. 동적 플러그인 로딩은 하지 않고 내장 연동의 선택적 활성화로 시작한다.
- 전역 파일(~/.claude/HEARTBEAT.md) 쓰기는 명시적 사용자 액션으로만 수행한다.
