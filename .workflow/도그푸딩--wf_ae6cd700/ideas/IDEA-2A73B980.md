연동 관리 UI의 model 편집을 자유 입력 스트링 필드 대신 지원 모델 드롭다운으로 바꾼다.

- 대상: 역할 잡 3종과 dream 잡의 model 필드 편집 UI.
- 사용자가 모델 별칭을 외워서 오타 없이 입력해야 하는 현재 방식은 조용한 실패(잘못된 모델명 → 세션 실패)로 이어질 수 있다. 고를 수 있게 하면 유저 경험이 좋아진다.
- 고민할 지점: 지원 모델 목록은 시간이 지나면 바뀐다. 목록의 출처와 갱신 방법, 그리고 목록에 없는 모델을 쓰고 싶은 사용자를 위한 직접 입력 여지를 기획에서 다뤄야 한다.
