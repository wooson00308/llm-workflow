최근 종료 목록의 실패 기록에 확인 처리를 두고 싶다.

실행 화면의 최근 종료 목록은 실패로 끝난 실행을 빨간 표시로 남긴다. 원인을 파악하고 조치까지 끝낸 기록도 그대로 남기 때문에, 목록을 열 때마다 같은 실패가 새 문제처럼 보인다. 이번 주에만 두 번, 이미 규명이 끝난 기록을 사용자가 새 장애로 오인해 다시 문의했다.

원하는 것: 사용자가 확인한 종료 기록은 기본 목록에서 접히거나 흐려지고, 전체 보기에서는 다시 볼 수 있다. 기록 자체는 지우지 않는다. 감사 용도로 남기는 성격이 우선이다. 확인 단위(개별, 일괄)와 표시 방식은 기획에서 정한다.
