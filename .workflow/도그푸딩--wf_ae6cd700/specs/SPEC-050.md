# 작업 중 표시를 어느 화면에서든 볼 수 있게 한다

## 결정권자 요약

지금은 에이전트가 문서를 작업 중이라는 표시가 오늘 화면에만 나온다. 사용자가 기획서나 작업
보드, 설정 같은 다른 화면을 보는 동안에는 세션이 돌고 있는지 알 수 없고, 확인하려면 오늘
화면으로 돌아가야 한다. 표시가 쓰는 값은 이미 프로젝트 조회에 들어 있어 새로 불러오는 값을
늘리지 않는다.

이 기획서는 모든 화면에서 공통으로 보이는 자리에 활성 세션 여부를 알리는 축약 표시를 추가하기로
정한다. 활성 세션이 없으면 표시를 완전히 숨기고, 누르면 지금과 같은 활동 화면으로 이동한다.
오늘 화면의 기존 상세 표시는 그대로 두어 세션이 도는지만 알리는 상시 표시와 역할을 나눈다.
사용자가 결정할 것은 이 배치와 정보량, 기존 표시와의 관계다. 승인하지 않으면 지금처럼 오늘
화면에서만 표시가 보인다.

## 기획 내용

에이전트 세션이 문서를 선점하면 오늘 화면 상단에 펄스 표시와 함께 담당 에이전트, 대상 문서,
활성 세션 수를 보여주는 카드가 나타난다. 이 카드를 누르면 활동 화면으로 이동한다. 문제는 이
표시가 오늘 화면을 벗어나면 사라진다는 점이다. 사용자가 기획서를 검토하거나 작업 보드를 보는
동안 세션이 끝났는지, 아직 도는지 알 방법이 없고 오늘 화면으로 돌아가야 확인할 수 있다.

표시가 쓰는 활성 세션 목록은 프로젝트를 조회할 때 이미 함께 내려오는 값이다. 오늘 화면이 아닌
곳에서 표시를 추가하더라도 이 값을 그대로 재사용하면 되고, 그 값을 얻기 위한 별도의 조회를
새로 만들 필요는 없다.

### 배치

화면을 전환해도 항상 같은 자리에 남아 있는 곳은 좌측 메뉴 영역이다. 오늘, 아이디어, 기획서,
개발, 기록, 활동 메뉴가 모두 이 영역 안에 있고 화면을 바꿔도 사라지지 않는다. 작업 중 표시는
이 메뉴 영역의 하단 쪽, 연동이나 설정으로 가는 자리 근처에 상시 노출 항목으로 추가한다.

### 정보량과 동작

- 활성 세션이 하나 이상일 때만 나타나고, 없으면 완전히 숨긴다. 빈 상태를 위한 자리 표시는
  두지 않는다.
- 오늘 화면의 기존 카드보다 정보량을 줄인 축약형으로 만든다. 펄스 점과 활성 세션 수만 보여주고
  담당 에이전트 이름이나 대상 문서 같은 세부 정보는 담지 않는다. 세부 정보는 이미 오늘 화면
  카드와 활동 화면에 있다.
- 눌렀을 때의 동작은 오늘 화면의 기존 카드와 같다. 활동 화면으로 이동한다.
- 활성 세션 수는 화면을 다시 불러오거나 프로젝트를 새로고침할 때 갱신되는 값을 그대로 따른다.
  이 기획서는 실시간 갱신 주기를 새로 정의하지 않는다.

### 오늘 화면 표시와의 관계

오늘 화면의 기존 카드는 지우지 않고 그대로 둔다. 오늘 화면에 있을 때는 상시 표시와 기존 카드가
함께 보인다. 상시 표시는 다른 화면에서도 세션이 도는지 여부만 알리는 최소 정보이고, 오늘 화면
카드는 진입 직후 바로 보이는 자리에서 담당 에이전트와 대상 문서까지 보여주는 상세 정보라서
목적이 다르다. 이 기획서는 두 표시를 하나로 합치지 않고 병행하는 쪽으로 정한다. 사용자가 이
결정에 동의하지 않으면 기획서를 반려하고 원하는 관계를 검토 의견으로 남긴다.

### 포함 범위

- 좌측 메뉴 영역에 상시 노출되는 작업 중 표시 추가.
- 활성 세션이 없을 때 표시를 완전히 숨기는 동작.
- 표시를 누르면 활동 화면으로 이동하는 동작.
- 이미 프로젝트 조회에 있는 활성 세션 값의 재사용.

### 제외 범위

- 활성 세션 값을 더 자주 갱신하는 실시간 구독이나 새로운 폴링 주기 도입.
- 오늘 화면 카드나 활동 화면이 보여주는 세부 정보(담당 에이전트, 대상 문서, 마이그레이션 보호
  안내)를 상시 표시에 추가하는 것.
- 세션별로 표시를 분리하거나 세션 목록을 상시 표시 안에서 펼쳐 보는 기능.
- 알림음이나 배지 카운트 같은 운영체제 수준의 알림 연동.

## 요구사항 명세

### R1. 작업 중 표시는 화면 전환과 무관하게 보인다

- 좌측 메뉴 영역에 상시 표시를 추가한다.
- 오늘, 아이디어, 기획서, 개발, 기록, 활동, 연동, 도움말, 설정 어느 화면에 있어도 활성 세션이
  있으면 표시가 보인다.
- 프로젝트를 전환하면 전환한 프로젝트의 활성 세션 값을 기준으로 표시를 다시 그린다.

### R2. 활성 세션 유무에 따라 나타나고 사라진다

- 활성 세션이 하나 이상이면 표시가 나타난다.
- 활성 세션이 모두 끝나면 표시가 사라진다.
- 활성 세션이 없는 상태에서는 빈 표시나 자리 차지용 여백을 남기지 않는다.

### R3. 정보량은 오늘 화면 기존 카드보다 줄인 축약형이다

- 세션이 도는지 여부와 활성 세션 수만 보여준다.
- 담당 에이전트 이름, 대상 문서, 마이그레이션 보호 안내 같은 세부 정보는 담지 않는다.

### R4. 누르면 활동 화면으로 이동한다

- 표시를 누르면 활동 화면으로 이동하는 동작은 오늘 화면의 기존 카드와 같다.
- 이미 활동 화면을 보고 있을 때 눌러도 오류 없이 그대로 머문다.

### R5. 새 데이터 조회를 추가하지 않는다

- 상시 표시는 프로젝트 조회에 이미 포함된 활성 세션 값을 그대로 사용한다.
- 상시 표시만을 위한 별도의 조회나 새로운 백엔드 명령을 추가하지 않는다.

### R6. 오늘 화면의 기존 카드는 그대로 둔다

- 오늘 화면에 있던 상세 카드는 지우지 않는다.
- 오늘 화면에 있을 때는 상시 표시와 기존 카드가 함께 보인다.
- 담당 에이전트, 대상 문서, 마이그레이션 보호 안내 같은 세부 정보는 지금처럼 오늘 화면 카드와
  활동 화면에서만 확인한다.

## 확인 필요

없다. 상시 표시의 위치, 정보량, 오늘 화면 기존 카드와의 관계를 이 기획서에서 정했다. 사용자가
이 배치 대신 다른 후보(상단 공통 띠, 화면 구석의 알약형 표시)나 오늘 화면 카드를 상시 표시로
통합해 없애는 쪽을 원하면 반려로 남겨 다음 초안에서 반영한다.

## 기대효과

- 사용자가 오늘 화면으로 돌아가지 않아도 세션이 도는지 확인할 수 있다.
- 기획서 검토나 작업 보드 확인처럼 오래 머무는 작업 중에도 세션 상태를 놓치지 않는다.
- 새 조회를 추가하지 않아 구현과 유지 비용이 낮다.

## 완료 조건

1. 활성 세션이 있는 상태에서 오늘이 아닌 화면(아이디어, 기획서, 개발, 기록, 활동, 연동,
   도움말, 설정)으로 이동해도 좌측 메뉴 영역에 상시 표시가 보인다.
2. 활성 세션이 하나도 없으면 어느 화면에서도 상시 표시가 보이지 않는다.
3. 상시 표시가 보이는 상태에서 활성 세션이 모두 끝나면 다시 불러온 뒤 표시가 사라진다.
4. 상시 표시에는 세션이 도는지 여부와 활성 세션 수만 보이고 담당 에이전트나 대상 문서 이름은
   보이지 않는다.
5. 상시 표시를 누르면 활동 화면으로 이동한다.
6. 오늘 화면에서는 상시 표시와 기존 상세 카드가 함께 보인다.
7. 프로젝트를 전환하면 상시 표시가 전환한 프로젝트의 활성 세션 값을 따른다.
8. 상시 표시를 추가하기 위해 새로 만든 조회 명령이나 폴링 주기가 없다.
