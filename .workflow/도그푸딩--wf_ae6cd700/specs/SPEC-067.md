# 새 기기 준비 단계를 하나의 안내로 잇고 실행 권한 동의에 상시 진입점을 둔다

## 결정권자 요약

### 제안

에이전트 화면에 남은 준비 단계만 순서대로 담은 안내를 하나 두고, 실행 권한 동의를 자동 배정 상태와 무관하게 언제든 열어 기록할 수 있게 한다.

### 현재

새 기기에서 자동 배정까지 가려면 관리형 서비스 연결, 실행 권한 동의, 자동 배정 켜기를 이 순서로 마쳐야 한다. 화면은 이것을 서비스 안내 배너와 꺼진 자동 배정 토글과 조건부 동의 배너 세 조각으로 흩어 놓았고, 세 조각은 서로가 같은 준비 과정의 일부라는 것을 알려주지 않는다. 동의 배너는 자동 배정이 이미 켜져 있을 때만 나타나는데, 서비스가 연결되지 않은 새 기기에서는 자동 배정 토글이 눌리지 않으므로 사용자가 그 조건을 만들 방법도 없다. 고급 설정의 동의 자리는 동의 여부와 고지 전문과 철회만 제공하고 동의를 기록하는 버튼이 없다. 그래서 새 기기에서 동의로 가는 길은 직접 배정을 하나 실행해 그 흐름 안에서 동의를 만나는 것뿐이고, 동의하려고 일감을 먼저 만드는 역순이 된다. 2026-08-18 Windows 새 기기 실측에서 확인한 순서다.

### 변경 후

에이전트 화면 위쪽에 남은 준비 단계만 담은 안내 하나가 선다. 연결, 동의, 켜기 순서로 서 있고 각 단계를 그 자리에서 실행하며, 이미 마친 단계는 완료로 표시되고 조작을 제공하지 않는다. 실행 권한 동의는 자동 배정이 꺼져 있어도 이 안내에서 열 수 있고, 고급 설정의 동의 자리에서도 기록할 수 있다. 새 기기 사용자는 일감을 먼저 만들지 않고 화면이 세워 준 순서대로 세 단계를 눌러 준비를 끝낸다. 세 단계가 모두 끝나면 안내는 사라지고 화면은 지금과 같은 구성으로 돌아간다.

### 비용과 위험

준비가 끝나지 않은 기기에서는 안내가 화면 위쪽을 차지한다. 준비가 끝나면 사라지므로 상시 점유는 아니고, 지금도 같은 자리를 배너 두 개가 쓰고 있어 새로 늘어나는 세로 길이는 단계 하나 분량이다. 동의를 여는 입구가 늘어나지만 동의 관문 자체는 그대로다. 고지 문구와 버전 판정, 동의 없이는 세션을 시작하지 않는 실행 조건, 직접 배정 흐름 안의 동의, 동의 철회 절차, 자동 배정 토글의 상시 자리, 사용자 승인과 품질 확인 관문은 모두 지금 그대로 둔다. 변경 범위가 에이전트 화면의 표시 규칙과 버튼 배치에 한정되므로 이전 표시로 되돌릴 수 있다. 이 기획서가 승인되지 않으면 지금 동선이 그대로 유지되고, 새 기기 사용자는 계속 직접 배정을 하나 만들어야 동의에 닿는다.

## 기획 내용

### 문제

준비 과정은 세 단계로 이어진 하나의 절차인데, 화면은 세 단계를 서로 모르는 세 조각으로 보여준다.

1. 서비스 안내 배너는 관리형 서비스가 등록되지 않았거나 실행되지 않을 때 나타나고, 상황에 맞는 계획 버튼을 제공한다.
2. 자동 배정 토글은 실행 환경이 정상일 때만 켤 수 있고, 그렇지 않으면 눌리지 않는다.
3. 동의 배너는 자동 배정이 켜져 있고 동의가 필요한 상태일 때만 나타난다.

새 기기는 1번이 미완이므로 2번을 켤 수 없고, 2번을 켤 수 없으므로 3번이 나타나지 않는다. 세 조각 중 동의만 조건이 다른 조각에 걸려 있어서, 준비를 순서대로 밟으려는 사용자가 두 번째 단계에서 갈 곳을 잃는다.

동의를 기록하는 기능 자체는 이미 있다. 지금도 자동 배정이 켜진 프로젝트에서 동의만 다시 받는 화면이 있고, 그 화면은 설정을 저장하지 않고 동의만 남긴다. 즉 이 기획서가 요구하는 것은 새로운 동의 기능이 아니라, 이미 있는 동의 화면을 여는 입구를 자동 배정 상태에서 떼어내는 일이다.

### 정하는 배치

원본 아이디어가 구체 배치를 기획에 맡겼으므로 여기서 정한다.

- 안내는 화면 제목 아래, 자동 배정 토글 위에 하나만 선다. 지금 그 자리에 있는 서비스 안내 배너와 동의 배너를 이 안내가 대신한다.
- 단계는 항상 연결, 동의, 켜기 순서로 세운다. 이 순서는 실제 선행 관계와 같다. 서비스가 연결되어야 자동 배정이 켜지고, 동의가 있어야 세션이 시작된다.
- 마친 단계는 목록에서 빼지 않고 완료로 표시한다. 사용자가 몇 단계 중 어디까지 왔는지 안내 하나만 보고 알 수 있어야 한다.
- 자동 배정 토글은 지금 자리에 그대로 둔다. 토글은 준비가 끝난 뒤에도 끄고 켜는 상시 조작이라 안내와 수명이 다르다. 안내의 세 번째 단계는 토글과 같은 확인 창을 여는 또 하나의 입구다.
- 안내는 프로젝트 하나의 상태를 말한다. 동의가 프로젝트별 기록이고 자동 배정도 프로젝트별 설정이므로, 프로젝트를 바꾸면 안내도 그 프로젝트의 남은 단계를 보여준다.

### 실행할 수 없는 단계를 다루는 방법

세 단계가 항상 실행 가능한 것은 아니다. 실행 환경이 동의 명령을 모르거나 동의 상태를 읽지 못하면 동의를 물어볼 수 없다. 이때 단계를 지우면 사용자는 그 단계가 끝난 것으로 오해하고, 버튼만 남기면 눌러도 아무 일이 일어나지 않는다. 그래서 그런 단계는 목록에 남되 지금 왜 진행할 수 없는지를 그 자리에 적고 버튼을 제공하지 않는다. 어느 쪽도 동의한 것으로 다루지 않는다는 기존 원칙을 그대로 따른다.

## 요구사항 명세

- R-01 에이전트 화면은 남은 준비 단계를 하나의 안내로 보여준다. 안내는 관리형 서비스 연결, 실행 권한 동의, 자동 배정 켜기를 이 순서로 담는다.
- R-02 각 단계는 무엇을 하는 단계인지와 지금 상태를 함께 보여주고, 진행할 수 있는 단계는 그 자리에서 실행하는 버튼을 제공한다.
- R-03 관리형 서비스 연결 단계는 실행 환경의 현재 상태에 해당하는 안내 문구와 조치 버튼을 그대로 사용한다. 설치, 연결, 복구, 재시작, 전환 준비를 이 단계 하나가 상황에 따라 나누어 보여준다.
- R-04 실행 권한 동의 단계는 자동 배정이 켜졌는지와 무관하게 나타난다. 동의가 필요한 상태이면 고지를 읽고 동의를 기록하는 화면을 이 단계에서 연다.
- R-05 자동 배정 켜기 단계는 자동 배정이 꺼져 있을 때 나타나고, 자동 배정 토글이 여는 것과 같은 확인 창을 연다.
- R-06 이미 마친 단계는 완료로 표시하고 조작 버튼을 제공하지 않는다.
- R-07 세 단계가 모두 끝나면 안내 전체가 사라진다.
- R-08 동의를 물어볼 수 없는 실행 환경에서는 동의 단계가 그 사유를 보여주고 동의 버튼을 제공하지 않는다. 이 경우에도 그 단계를 완료로 표시하지 않는다.
- R-09 고급 설정의 실행 권한 동의 자리는 동의가 필요한 상태일 때 고지를 읽고 동의를 기록하는 버튼을 함께 제공한다. 지금 있는 동의 여부, 동의 시각, 고지 버전, 고지 전문 다시 읽기, 동의 철회는 그대로 둔다.
- R-10 동의만 기록하는 경로는 자동 배정 설정을 저장하지 않는다. 동의를 기록해도 자동 배정은 꺼진 채로 남는다.
- R-11 실행 환경 상태를 읽지 못했을 때의 오류 안내는 지금과 같은 자리에 그대로 남는다.

## 범위 밖

- 동의 고지 문구, 고지 버전 규칙, 동의 유효성 판정은 바꾸지 않는다.
- 실행 환경의 설치, 연결, 복구, 전환 절차 자체는 바꾸지 않는다. 안내는 이미 있는 조치를 한자리에 모아 놓을 뿐이다.
- 자동 배정 판정, 세션 시작 조건, 직접 배정 흐름은 바꾸지 않는다. 직접 배정 흐름 안의 동의도 지금처럼 남는다.
- 고급 설정의 나머지 절인 역할 설정, 실행 환경, 실행 도구, 기존 설정 이전은 바꾸지 않는다.
- Windows 전용 처리를 두지 않는다. 실측한 기기가 Windows였을 뿐 조건은 운영체제와 무관하다.

## 수용 기준

- AC-01 서비스 미등록, 동의 없음, 자동 배정 꺼짐 상태에서 에이전트 화면을 열면 세 단계가 순서대로 있는 안내가 하나 보인다.
- AC-02 같은 상태에서 두 번째 단계의 버튼으로 동의 화면을 열어 동의를 기록할 수 있다. 직접 배정을 만들지 않고 도달한다.
- AC-03 자동 배정이 꺼진 상태에서 동의를 기록하면 동의 상태가 동의함으로 바뀌고 자동 배정은 꺼진 채로 남는다.
- AC-04 관리형 서비스 연결을 마치면 안내의 첫 단계가 완료로 표시되고 남은 두 단계가 그대로 보인다.
- AC-05 세 단계를 모두 마치면 안내가 사라지고, 화면에는 자동 배정 토글과 실행 목록이 지금과 같은 구성으로 남는다.
- AC-06 동의 명령을 모르는 실행 환경에서 안내를 열면 동의 단계에 그 사유가 보이고 동의 버튼이 없으며, 그 단계는 완료로 표시되지 않는다.
- AC-07 준비를 모두 마친 프로젝트에서 동의를 철회하면 안내가 다시 나타나고 동의 단계만 남는다.
- AC-08 고급 설정을 열면 동의가 필요한 상태에서 동의를 기록하는 버튼이 보이고, 동의한 상태에서는 지금처럼 철회 버튼이 보인다.

## 기대효과

- 새 기기 사용자가 화면이 세워 준 순서대로 세 단계를 밟아 자동 배정에 도달한다. 동의하려고 일감을 먼저 만드는 역순이 없어진다.
- 준비가 어디까지 되었는지를 안내 하나로 확인할 수 있어, 세 조각을 각각 해석하고 서로의 관계를 짐작하는 부담이 없어진다.
- 실행 권한 동의가 자동 배정 상태에 묶이지 않으므로, 동의가 필요해지는 모든 경우에 같은 자리에서 같은 방법으로 동의할 수 있다.
