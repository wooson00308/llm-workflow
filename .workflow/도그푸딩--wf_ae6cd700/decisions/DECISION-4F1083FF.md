사용자 지시로 대리 기록한 승인. 아이디어(IDEA-48EDAF2B)와 세션 합의(대행 설치 금지, 가이드+감지 마법사)와의 정합을 확인했다. 확인 필요 1~6번은 모두 기획서의 제안대로 진행한다 — 1번(패키지 단계는 독립 감지 없이 2단계에서 함의), 2번은 (A)안(macOS만 감지, 나머지 플랫폼은 확인 불가 + 명령 안내), 3번(다시 확인 버튼 없이 자동 확인 사실 표기), 4번(표시 조건을 필수 단계 미완료로 넓히는 해석 승인 — 이것이 이 기획서의 핵심 가치다), 5번(복사 수단은 아키텍트 재량, 클립보드 플러그인 의존성 추가에 반대하지 않음), 6번(SPEC-015 파생 작업 뒤에 서도록 depends_on으로 선언).

검토에서 함께 결정한 사항 하나를 남긴다.

- 3단계(서비스 등록) 감지에 R4의 원칙을 그대로 적용해 달라. 표준 아티팩트(`com.claude-heartbeat.plist`)가 없다는 것은 "등록 안 됨"의 충분한 근거가 아니다 — 사용자가 다른 라벨로 등록한 설치가 실존한다(이 저장소의 도그푸딩 머신이 `com.catze.dream-heartbeat.plist`로 등록해 데몬이 실제로 돌고 있다). 표준 아티팩트가 없으면 3단계를 미완료로 단정하지 말고, 확인 불가와 "다른 이름으로 등록해 데몬이 이미 돈다면 이 단계는 끝난 것"류의 안내로 다뤄 마법사가 정상 설치를 영구히 미완료로 표시하지 않게 해달라. 구체 판정 규칙은 아키텍트가 정한다.
