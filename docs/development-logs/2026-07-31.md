## 문서 뷰어 GFM 렌더링 지원

- 범위: 기획서·작업 상세의 문서 뷰어가 `*강조*`, 코드 펜스 등 Markdown을 평문으로 보여주는 문제를 고쳐 GitHub 프리뷰 규격으로 렌더링한다.
- 결정: 줄 단위 수제 파서를 `react-markdown` + `remark-gfm`으로 교체한다. raw HTML은 기본 비렌더 유지(LLM 작성 문서 안전), 링크는 `target="_blank"` + `noopener`로 처리한다.
- 변경: `MarkdownBody` 재작성, `App.css`의 `.markdown-body`에 굵게·기울임·인라인 코드·코드 펜스·인용·테이블·취소선·체크리스트·링크·구분선·이미지 스타일 추가(종이 톤 유지). 구 렌더러 전용이던 `.markdown-space` 제거.
- 검증: `npm run check` 통과(테스트 25개 — GFM 요소별 렌더 테스트 신설). Playwright 스크린샷으로 표·코드 펜스·체크리스트 실렌더 확인.
- 후속: Tauri 웹뷰에서 `target="_blank"` 외부 링크가 열리는지 실앱 확인 필요. 안 열리면 opener 플러그인 연동을 port 계층에 추가한다.
