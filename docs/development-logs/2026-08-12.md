# 2026-08-12 개발 기록

## 에이전트 자동 배정·작업 대기열 UX 전면 개편

- 범위: 에이전트 관제 화면, 자동 배정 opt-in, 직접 배정 dialog, 고급 설정 drawer, 전체 자격 대기열, watcher 갱신, 연동 화면 폐기, 기존 역할 잡 이전, 런타임 0.9.0 bundle.
- 기본 화면: `작업/설정` 탭과 상시 실행 폼을 제거했다. 헤더에는 작은 실행 환경 상태·`직접 배정`·`고급 설정`만 두고, 본문은 `내 선택 대기`, `확인 필요`, `진행 중`, `배정 대기`, `최근 종료`를 상태가 있을 때만 보여 준다. 자동 배정 기본값은 꺼짐이다.
- 계약: 대상 없음은 실패 행을 만들지 않는 정상 `작업 대기 중`으로 처리한다. 프로젝트 payload는 역할별 전체 자격 후보와 제외 사유를 포함하고, 상세 기술 값과 제어는 dialog/drawer로 숨긴다.
- 갱신: 2.5초 전체 프로젝트 반복 조회를 제거하고 프로젝트 파일 watcher 알림과 활성 화면·활성 실행 중의 가벼운 상태 조회를 분리했다. watcher 저하 시 안전 확인 주기로 계속 동작한다.
- 설정: 역할·provider·모델·인원·안전 확인 주기는 고급 설정으로 이동했다. 기기·프로젝트 한도는 권장값과 다른 프로젝트 합·현재 사용량을 함께 보여 주며 사용자의 상향 선택을 막지 않는다.
- 연동: 사이드바 연동 메뉴와 Dream 관리 UI/API를 제거했다. 런타임 설치·복구와 기존 역할 잡 이전은 `고급 설정`으로 이동했다. 이전은 새 정책을 자동 배정 OFF로 저장한 뒤 앱 소유 역할 잡만 중지하고 서비스 전환을 검증하며, 실패 시 역할 잡을 복구한다.
- 실기 전환: workflow-labs의 기존 기획자·아키텍트·개발자 jobs.d 파일만 제거했다. mech-arena 잡은 유지했고 외부 `com.catze.dream-heartbeat.plist`는 SHA-1 `2c7b580d806341e840ea92cc8079d03bb4092741`로 불변이다. 자동 배정은 실제 DB에서도 꺼짐이다.
- 런타임: 앱 최소 버전을 0.9.0으로 올리고 검증된 macOS universal2 런타임을 bundle했다. stable launcher가 서비스 정의에 전달되며 앱 종료 뒤에도 dispatcher가 running 0.9.0으로 유지된다.
- 시각 QA: 최신 universal debug 앱을 1180px와 940px에서 확인했다. 헤더 개행·가로 스크롤 없이 관제 정보가 유지됐고, 940px 고급 설정은 본문 위 sheet로 렌더됐다. 앱은 940px 에이전트 화면에 열어 뒀다.
- 검증: 프런트 24 files, 446 passed·42 skipped, typecheck, production build. Rust 718 lib + 19 e2e, fmt, Clippy `-D warnings`. bundled runtime contract 0.9.0/API 1/macos-universal과 앱·runtime Mach-O 양 architecture 확인.
- 보호: 사용자와 워크플로 역할이 만든 `.workflow` 변경은 수정하지 않았다. 자동 배정을 켜거나 유료 provider 실행을 시작하지 않았다.
- 남은 위험: Linux·Windows 실제 앱 bundle/service smoke는 target CI 또는 해당 OS 기기에서 확인해야 한다.
