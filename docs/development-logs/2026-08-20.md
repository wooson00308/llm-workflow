## 앱밖세션 유출의 근본 수정(재입양) 다이렉트 구현 (대화 세션)

- 발단: 사용자 진단 — "앱이 배정한 세션이 앱밖세션으로 빠져 카운트되지 않는 게 근본 문제". SPEC-081(앱 밖 세션 표시 개선)은 그 증상을 서술하는 방향이었고, 검증까지 끝난 판정 유닛이 즉살 사유를 "앱 사정" 화면 근거로 분류하는 것을 코드로 확인. TASK-S081-02 막힘은 하트비트 대기가 아니라 정의 오류(A1이 SPEC-069 제외 규칙과 모순).
- 사용자 결정: QA 수정요청 루프 대신 다이렉트 해결. PR #40에 2커밋으로 재입양 추가.
  - sweep이 복구 단계가 놓은 실행을 매 주기 재판정: 감독자 생존·신원 일치면 감독자에게 복귀, 감독자 없이 provider 생존·신원 일치면 감독 소유를 비운 활성 실행으로 재입양(이후 데몬 재조정이 이벤트·lease·종료 정리 이어받음). reconcile의 supervisor_gone 드롭도 같은 조건에서 입양으로 대체.
  - 재입양된 실행은 활성으로 집계되고 앱 밖 세션 목록에서 빠짐 — 허위 즉살 증상이 한 주기 내 자가 치유. 취소 잔여 실행은 부활 금지, 판정 불가는 점유 유지.

- 남은 판단(사용자): SPEC-081·GROUP-081 처분 — 재입양이 병합되면 겹침 판정의 실효 대상이 사라짐. S081-01(판정 유닛)은 읽기 전용이라 무해, S081-02는 막힘 상태 유지 중. QA 수정요청 또는 그룹 정리는 복귀 후 도장으로.
