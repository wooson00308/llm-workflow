- 범위: 워크플로우 생성 프로젝트에만 적용되는 외부 LLM 사용 규칙과 Claude Code·Codex 진입점을 안전하게 설치한다.
- 결정: 글로벌 규칙은 사용하지 않고, 상세 규칙은 `.workflow/rules/workflow.md`를 단일 원본으로 둔다.
- 결정: Codex는 루트 `AGENTS.md`, Claude Code는 `CLAUDE.md`의 `@AGENTS.md` import를 진입점으로 사용한다.
- 결정: 기존 진입점 파일은 앱 관리 마커 밖의 내용을 보존하며, 손상된 마커나 비관리 규칙 파일은 자동 덮어쓰기 대신 충돌로 처리한다.
- 변경: 별도 `project_instructions` 모듈에 공급자 중립 규칙 템플릿, 사전 충돌 검증, 원자적 저장과 진입점 병합을 구현했다.
- 변경: 신규 워크플로우 생성 전에 규칙 충돌을 검사해 실패 시 `.workflow`가 부분 초기화되지 않도록 했다.
- 검증: 최초 설치, 기존 파일 보존, 기존 Claude import 재사용, 재실행 멱등성, 손상 마커와 비관리 규칙 파일 충돌을 포함한 Rust 테스트 20개가 통과했다.

- 범위: 아이디어·기획서·개발 메뉴가 동일한 3열 화면을 공유하던 구조를 각 작업 목적에 맞는 독립 화면으로 개편한다.
